- 🚀 **QHacettepe** kuantum topluluğunun **kurucu ortağı**yım ve topluluğun **ilk başkanlığı**nı üstlendim
- 🌱 Kuantum programlama, Qiskit ve kuantum algoritmaları üzerine içerik üretmeye devam ediyorum
